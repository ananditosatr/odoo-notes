# Odoo Notes

Catatan belajar Odoo yang berawal dari mata kuliah Sistem Enterprise. Level penggunaan saat ini: dasar.

## Rencana alur belajar

Alur berikut adalah rencana untuk dicoba dan didokumentasikan, bukan klaim bahwa seluruh langkah sudah dilakukan:

1. Menyiapkan perusahaan, produk, dan pelanggan.
2. Mengikuti alur **Quotation > Sales Order > Invoice**.
3. Memeriksa stok melalui **Inventory**.
